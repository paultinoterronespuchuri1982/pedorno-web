# PEDORNO

Página web de una sola pantalla para el proyecto musical PEDORNO. Incluye la presentación del proyecto, galería de fotos, material gráfico de discos e insertos, y un reproductor de audio.

## Contenido

```
index.html   # Página completa (HTML y CSS integrados)
img/         # Fotografías, portadas, insertos y el audio motor.mp3
```

## Cómo ver

No requiere instalación. Abra `index.html` en el navegador.

## Notas de mantenimiento

- Muchas imágenes están en versión de alta resolución (`*-hd.jpg`). Conviene generar versiones optimizadas para la web (WebP o tamaños reducidos) para mejorar la carga.
- Los nombres de archivo con espacios o caracteres especiales (`IMPRESIÓN DISCO.jpg`, `]sea and tech.png`) pueden fallar en algunos servidores. Renómbrelos antes de publicar.
